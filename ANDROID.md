# Telegram Links для Android

Нативно упакованное Python-приложение с сенсорным интерфейсом Kivy. Минимум Android 7 (API 24), ARM64 или ARM32. Установка Python не нужна. Сборка debug APK предназначена для установки напрямую, не для Google Play.

Возможности: вход в свой Telegram с кодом и 2FA, три режима сканирования, фильтр Combot CAS, объединение постов в каналы, сохранение API, кнопки вставки, остановка с частичным результатом, экспорт TXT/HTML через системный выбор файла Android.

Установка: перенесите APK на телефон, откройте и разрешите этому источнику установку приложений, если Android запросит. После установки введите собственные API ID/Hash и номер телефона. Для API используйте https://my.telegram.org/apps.

При сборе держите приложение открытым и экран включённым: фоновая служба не реализована, Android может остановить приложение в фоне. «Остановить и сохранить» сохраняет промежуточный результат; принудительное закрытие/выгрузка ОС этого не гарантирует. После сбора нажмите сохранение TXT или HTML и выберите папку, например Downloads. Кликабельный документ — HTML.

API и сессия хранятся в приватном каталоге приложения, резервное копирование Android отключено. При удалении приложения эти данные и внутренние выгрузки удаляются, поэтому нужные результаты экспортируйте. API сохранён без дополнительного шифрования внутри приватного каталога; пароль 2FA и код не сохраняются.

Сборка выполняется workflow Build Android APK в GitHub Actions. Windows/macOS версии остаются отдельными приложениями. Для обновлений без удаления требуется та же подпись APK; текущие сборки используют debug-ключ окружения сборки.
