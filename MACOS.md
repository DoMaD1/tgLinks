# TelegramLinks для Mac

Это комплект исходников и автоматической сборки, **не готовое приложение .app**. Сборка должна выполняться на macOS. Локально на Windows её выполнить нельзя. Для пользователя готовой .app Python не потребуется.

## Получить сборку, имея только Windows

1. Создайте репозиторий на GitHub (можно приватный) и загрузите содержимое комплекта в его корень. Важно сохранить файл `.github/workflows/macos.yml`; при загрузке через браузер скрытая папка может не попасть в выбор — тогда создайте файл с этим путём вручную и вставьте содержимое из комплекта. Не загружайте ваш рабочий каталог целиком с сессиями и выгрузками.
2. Откройте вкладку **Actions → Build macOS app → Run workflow**.
3. Workflow запустит два облачных Mac: Apple Silicon и Intel. Он проверит код, соберёт приложение и запустит собранный исполняемый файл с автоматической проверкой окна и экспорта.
4. После зелёного результата откройте выполненный запуск и скачайте **Artifacts**: `TelegramLinks-macOS-arm64` для Apple Silicon (M1 и новее) либо `TelegramLinks-macOS-x64` для Intel.
5. Внутри скачанного артефакта будет ZIP с `.app`. Передавайте этот внутренний ZIP без распаковки на Windows, чтобы сохранить структуру и права приложения.

Доступность macOS runners и расход минут зависят от настроек/тарифа GitHub. Матрица сборки использует macOS 15; совместимость с более старыми версиями системы здесь не подтверждена.

## Как проверить с Windows

Зелёный workflow подтверждает тесты и пробный запуск **на настоящем окружении macOS**, управлять им можно из браузера Windows. Он не проверяет ваш Telegram-аккаунт, доставку кодов входа или разрешения macOS на скачанную сборку.

Для полной ручной проверки нужен человек с Mac или удалённый Mac. Проверьте: открытие приложения, кнопки вставки и Cmd+V, вход с кодом и паролем, поиск в тестовом чате, остановку и открытие HTML. Сам файл `.app` в Windows не запускается.

Сборка не подписана сертификатом Developer ID и не нотариализована Apple; автоматическая проверка не гарантирует отсутствие предупреждений Gatekeeper на другом Mac. Для распространения без этих предупреждений потребуется подпись и нотариализация на стороне владельца приложения.

## Собрать непосредственно на Mac

Установите Python 3.13 с Tkinter (например, установщиком с python.org), распакуйте этот комплект. Откройте Terminal в его папке и выполните:

```bash
bash build_macos.sh
```

После успешной проверки результат будет в `dist/TelegramLinks-macOS-arm64.zip` или `dist/TelegramLinks-macOS-x86_64.zip`.

На Mac результаты по умолчанию сохраняются в `~/Downloads/TelegramLinks`, сессия — в `~/Library/Application Support/TelegramLinkExporter`. Данные аккаунта в сборку не включаются.

Ссылки: https://pyinstaller.org/en/stable/usage.html и https://docs.github.com/en/actions/reference/runners/github-hosted-runners.
