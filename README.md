# Ссылки из Telegram

Версия 1.4: фильтр Combot CAS включён по умолчанию и убирает адреса `t.me/combot/cas` с любыми параметрами, в том числе из кнопок. Его можно отключить. Другие ссылки и их параметры не объединяются. Старые выгрузки не изменяются.

API ID и API Hash сохраняются при запуске сбора, закрытии окна или нажатии «Сохранить настройки». Чтобы удалить сохранённые ключи, снимите «Запоминать API ID и API Hash». Настройки хранятся локально в `settings.json` рядом с сессиями (без шифрования); в EXE/.app и репозиторий они не включаются. Коды входа и пароль 2FA не сохраняются.

Приложение на Python с окном на русском языке. Читает всю доступную историю одного чата и сохраняет ссылки без повторов в `links.txt` и `links.html`. HTML открывается в браузере: ссылки кликабельные. TXT — обычный текст, кликабельность зависит от редактора.

## Запуск в Windows

### Готовый EXE

Откройте `dist\TelegramLinks.exe`. Python и установка библиотек не нужны. Для передачи другим людям достаточно этого EXE: сессии и данные входа в него не включены. Каждый пользователь вводит свои данные. Результаты по умолчанию сохраняются в `exports` рядом с EXE, поэтому размещайте его в доступной для записи папке.

Для повторной сборки из исходников запустите `build.bat`. Сборка выполняется через PyInstaller: https://pyinstaller.org/en/stable/usage.html.

### Из исходников

1. Установите Python 3.10 или новее с компонентами Tcl/Tk и Python Launcher.
2. Запустите `start.bat`. При первом запуске нужен интернет для установки Telethon.
3. Получите собственные **API ID** и **API Hash** на https://my.telegram.org/apps, раздел API development tools. Это не токен бота. Инструкция Telegram: https://core.telegram.org/api/obtaining_api_id.
4. Введите API ID, API Hash, телефон в международном формате и чат, например `@pl_warszawa_rabota` или `https://t.me/pl_warszawa_rabota`. Можно указать числовой ID уже доступной аккаунту группы.
5. Нажмите «Собрать ссылки». При первом входе введите код Telegram, а при включённой двухэтапной аутентификации — пароль.
6. Дождитесь завершения и нажмите «Открыть результат». Каждый запуск создаёт отдельную папку в `exports` или выбранном каталоге.

Ручной запуск:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## Что собирается

Версия 1.3 добавляет выбор режима:

- **Полная история** — проверка всех доступных сообщений, как раньше. Выбрана по умолчанию.
- **Быстро: ссылки Telegram** — серверный фильтр URL; сообщения без распознанных Telegram ссылок не загружаются. Может пропускать ссылки в кнопках и нераспознанные адреса. Для максимальной полноты используйте полную историю.
- **Последние 5000 сообщений** — проверка только последних 5000 доступных сообщений.

Режим и его ограничения записываются в HTML и `info.txt` рядом с результатами. Поле статуса показывает число прочитанных сообщений, ссылок и прошедшее время. Интервал запросов снижен с автоматической секунды до 0,5 секунды; если Telegram требует паузу, программа соблюдает её и снижает частоту запросов. Ускорение зависит от сети и серверных ограничений, фиксированный прирост не гарантируется.

Готовая версия 1.3: `dist\v1.3\TelegramLinks.exe`. Кнопки вставки сохранены.

- URL из текста и подписей, включая домены без протокола, размеченные Telegram как ссылки.
- Скрытые ссылки под текстом и URL кнопок.
- Неразмеченные адреса, начинающиеся с `http://`, `https://`, `tg://`, `www.`, `t.me/` или `telegram.me/`.
- Дубликаты удаляются после приведения регистра протокола и домена; пути, параметры и якоря сохраняются. HTTP и HTTPS считаются разными адресами.

История читается от новых сообщений к старым. При остановке или ошибке во время чтения сохраняется частичный результат с соответствующей отметкой в HTML. При ограничении частоты Telegram программа ждёт указанное сервером время; ожидание можно остановить.

Удалённые сообщения и недоступная аккаунту история не собираются. Программа не вступает в группы по приглашениям. Комментарии в связанной группе нужно выгрузить отдельно. Ссылки внутри изображений и прикреплённых файлов не распознаются; @упоминания и email не считаются URL.

## Данные входа

API Hash, коды и пароль приложение не записывает в настройки. Можно задать `TG_API_ID` и `TG_API_HASH` через переменные окружения. Сессия входа хранится в `%LOCALAPPDATA%\TelegramLinkExporter` отдельно для каждого введённого номера. Не передавайте файлы `.session` другим людям: они дают доступ к аккаунту. Отозвать вход можно в Telegram → Настройки → Устройства; после закрытия программы можно удалить локальную сессию.

## Проверка

```powershell
py -3 -m unittest discover -s tests -v
```

Тесты проверяют извлечение ссылок, Unicode-разметку Telegram, дедупликацию и безопасный HTML. Проверка реальной выгрузки требует вашего аккаунта Telegram.
